EXERCÍCIO 1 

Escreva o método contarAprovados que recebe um vetor de notas inteiras (0 a 100) e devolve quantas são maiores ou iguais a 60. 

Assinatura: public static int contarAprovados(int[] notas) 

Esperado: {80,45,60,59,100} devolve 3; {10,20,30} devolve 0; {} devolve 0. 

  

EXERCÍCIO 2 

Escreva o método posicaoDoMaior que recebe um vetor de inteiros e devolve o índice do maior elemento. Em caso de empate, o da primeira ocorrência. Vetor vazio devolve -1. 

Assinatura: public static int posicaoDoMaior(int[] valores) 

Esperado: {3,9,2,9,1} devolve 1; {5} devolve 0; {-4,-9,-2} devolve 2; {} devolve -1. 

  

EXERCÍCIO 3 

Escreva o método somarPares que recebe um vetor de inteiros e devolve a soma apenas dos elementos pares e positivos. Se não houver nenhum, devolve 0. 

Assinatura: public static int somarPares(int[] numeros) 

Esperado: {1,2,3,4,5,6} devolve 12; {-2,-4,3} devolve 0; {0,2} devolve 2.
