EXERCICIO 1

Enunciado: Escreva o metodo contarAprovados que recebe um vetor de notas inteiras (de 0 a 100) e devolve quantas notas sao maiores ou iguais a 60.

Assinatura: public static int contarAprovados(int[] notas)

Comportamento esperado:

  • Entrada {80, 45, 60, 59, 100} devolve 3
  • Entrada {10, 20, 30} devolve 0
  • Entrada {60} devolve 1
  • Entrada {} devolve 0

Nivel taxonomico alvo: Aplicar

EXERCICIO 2

Enunciado: Escreva o metodo posicaoDoMaior que recebe um vetor de inteiros e devolve o indice do maior elemento. Em caso de empate, devolve o indice da primeira ocorrencia. Se o vetor estiver vazio, devolve -1.

Assinatura: public static int posicaoDoMaior(int[] valores)

Comportamento esperado:

  • Entrada {3, 9, 2, 9, 1} devolve 1
  • Entrada {5} devolve 0
  • Entrada {-4, -9, -2} devolve 2
  • Entrada {} devolve -1

Nivel taxonomico alvo: Analisar

EXERCICIO 3

Enunciado: Escreva o metodo somarPares que recebe um vetor de inteiros e devolve a soma apenas dos elementos pares e positivos. Se nao houver nenhum, devolve 0.

Assinatura: public static int somarPares(int[] numeros)

Comportamento esperado:

  • Entrada {1, 2, 3, 4, 5, 6} devolve 12
  • Entrada {-2, -4, 3} devolve 0
  • Entrada {0, 2} devolve 2
  • Entrada {7, 9} devolve 0

Nivel taxonomico alvo: Aplicar
